Demo/static admin module built with HTML5, Bootstrap 5, CSS and JavaScript.

Core pages:
- admin-dashboard.html
- manage-customers.html
- manage-artisans.html
- manage-products.html
- manage-categories.html
- manage-orders.html
- admin-payments.html
- admin-shipments.html
- manage-complaints.html
- admin-custom-orders.html
- commission-settings.html
- admin-settlements.html
- reports.html
- admin-notifications.html
- audit-logs.html

All data is demo-only for frontend presentation and can later be connected to Spring Boot REST APIs.
