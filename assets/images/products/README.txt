KALAKART PRODUCT IMAGES

Replace the SVG placeholder for any product with your real JPG/PNG/WebP photo.
Then change only the `image:` value for that product in ../../js/products.js.

Example:
image:'assets/images/products/my-resin-tray.jpg'

Recommended image size: 900 x 1100 px (portrait) or similar ratio.
Keep file names simple: resin-tray-01.jpg
